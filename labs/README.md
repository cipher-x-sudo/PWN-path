# Labs

These labs are intentionally small and local. They are for learning debugger
workflow and exploit construction in a controlled environment.

## Order

1. `phase1-stack-basics`
2. `phase2-ret2win`
3. `phase2-ret2win-arg`
4. `phase2-ret2win-2args`
5. `phase2-ret2win-3args`
6. `phase2-cyclic-offset`
7. `phase2-stack-alignment`
8. `phase2-stack-alignment-sse`
9. `phase2-ret2libc-leak`

More advanced labs can be added as you progress:

- format string leak/write
- more ret2libc and ROP
- tcache poisoning
- UAF
- stripped reversing challenge
